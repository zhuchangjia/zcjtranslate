# 指译 ZCJ Translate

- [开发构建与发布说明](BUILD.zh-CN.md)
- [产品安装使用说明书](USER_GUIDE.zh-CN.md)

Windows 上用于 Chrome / Edge 的纯离线网页取词扩展。内置初中、高中、四级、六级、专八、ECDICT 通用英汉词库、常用日中词库及 OPUS-MT 英译中模型。

工具栏弹窗提供“打开 PDF / Word”，可在扩展自己的离线阅读器中打开本机文字型 PDF 或 DOCX，并复用相同的选词、悬停和整句翻译。PDF 采用原页面 Canvas 加透明文字层显示，保留原文档的图片、字体和页面版式。文件只在本机解析，不会上传；扫描图片型 PDF 暂不包含 OCR。

鼠标停在英文单词或日文词语上约 0.5 秒即可自动取词，适用于不方便选择的超链接文字；悬停翻译框显示后，只要鼠标继续移动就会立即关闭并从新位置重新计时。可在扩展弹窗中关闭悬停取词。

英文句子和段落优先使用安装包内置的 OPUS-MT 英译中量化模型进行整句翻译；首次使用需要加载模型，失败时自动保留本地逐词结果。模型和 WASM 推理运行库均在扩展包内，断网可用。长文本会自动分句分块，没有总字符数限制。

默认在网页进入空闲状态后预加载英日词典和 OPUS-MT 模型，多个标签页共享同一份后台缓存，以降低第一次查词和第一次整句翻译的等待时间。可在扩展弹窗中关闭预加载以减少内存占用；关闭后仍会在首次使用时按需加载并继续缓存。

OPUS-MT 保持模型默认的 4 路 Beam Search 以维持翻译质量，并在支持跨域隔离的 Chrome/Edge 扩展离屏页面中使用 4 个 WASM 线程加速本地推理。

离线引擎固定使用 WASM，不请求 WebGPU 适配器；因此没有独立显卡或浏览器禁用 WebGPU 时也可运行。随包的 Transformers.js 浏览器构建已移除与本项目无关的 WebGPU 探测日志，以及其对 MarianTokenizer 固定输出的兼容性警告；实际运行错误仍会正常显示。

## 安装（无需编译）

### Microsoft Edge

1. 地址栏打开 `edge://extensions`。
2. 打开左侧的“开发人员模式”。
3. 点击“加载解压缩的扩展”，选择本项目目录。

### Google Chrome

1. 地址栏打开 `chrome://extensions`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本项目目录。

安装后浏览器会在后台管理扩展；浏览器最小化不影响已经打开网页中的取词。首次安装前已打开的网页需要刷新一次。

## 使用

- 用鼠标选择一个英文或日文词语：自动弹出本地释义。
- 双击英文单词：弹出中文释义、音标及考试级别。
- 选择日文汉字或假名词：弹出假名读音、词性及中文释义。
- 选择一段英文或日文：将所选内容完整翻译为中文。
- 选择文字没有总字符数量限制；较长内容会在本机自动分段顺序处理。
- 段落浮窗不重复显示所选原文，只显示本地整句译文和难词结果。
- 浮窗左侧与所选文字的最左侧对齐，并向右延伸到屏幕边缘；选择位置过于靠右时自动保证最小可读宽度。
- 段落结果不再显示“完全离线逐词翻译”级别标签。
- 翻译框始终从鼠标或选区下沿向屏幕底部展开，不再翻到原文上方；宽度占满屏幕可用宽度，高度取当前位置到屏幕底部的剩余空间。内容放不下时先自动缩小字号，达到可读下限后才在框内滚动。
- 点击扬声器按钮：播放英语或日语读音。
- `Alt+T`：翻译当前选择内容。
- 右键选中文字，选择“用指译翻译”。
- 点击工具栏扩展图标，可切换为仅双击/快捷键触发。
- 点击“打开 PDF / Word”并选择本机文档，可在离线阅读器中翻译文档文字。
- PDF 普通拖选不方便时，可开启阅读器顶部的“框选翻译”，在同一页拖出矩形后自动提取并翻译框内文字；按 `Esc` 可退出框选模式。

## 技术结构与扩展点

- `src/content.js`：网页取词和浮窗，不依赖具体翻译服务。
- `src/background.js`：语言策略和本地词典适配层。后续可增加其他语言词库或离线翻译模型。
- `src/content.js`：网页取词、结果浮窗和发音交互。
- `data/dictionary.json`：构建时生成的初中、高中、四六级、专八紧凑本地词典索引。
- `data/common-supplement.json`：常用缺词补充库，可持续加入独立音标和释义。
- `data/ecdict-fallback.json`：由 ECDICT 筛选生成的通用离线英汉兜底词库。
- `data/japanese-dictionary.json`：日语汉字/假名双索引的本地日中词典。
- `targetLanguage: auto`：通过浏览器 UI 语言推断操作系统语言；后续可扩充语言映射。
- 约 40 万个英文词条及中文释义均在扩展包内；源词典提供音标的条目会离线显示音标。朗读使用本机语音，不依赖音标字段。
- 发音使用 Web Speech API 和 Windows 已安装语音；系统安装相应英语/日语语音后即可离线播放。
- 英文段落按单词切分；日文采用本地词库最长匹配切分。“本地难词 TOP 10”会过滤高频基础词和日语助词，再按考试级别、词形长度等难度因素排序，只显示最难的10个词，以“原词：释义 ｜ 原词：释义”展示；它是词汇提示，不等同于能调整语序的机器翻译。

## 当前边界

- 浏览器内置页面（如 `edge://`）、扩展商店和 PDF 内置查看器通常禁止内容脚本运行。
- 发音使用扩展专用 `chrome.tts` 接口。英文使用浏览器默认可用语音，避免部分 Windows 环境指定 `en-US` 后静默无声；日文优先使用日语语音，找不到时回退默认语音。
- 英语和日语通过字符范围自动识别；混合语言将在后续版本增强。
- 悬停取词容易误触且逐字定位在不同网页上不稳定，因此 MVP 使用选中/双击；架构允许后续增加悬停触发器。

## 隐私

单词查询、难词筛选和 OPUS-MT 整句翻译全部在本机完成。扩展不发送所选文字，不收集浏览历史，也不保存查询内容。

第三方词库来源和许可证见 `THIRD_PARTY_NOTICES.md`。
